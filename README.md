# UoME Website

A modern, mobile-first website for **UOM Enterprise Ltd (UoME)** in Ebene, Mauritius, the delivery partner for University of Lancashire programmes. It is designed to attract, inform and convert prospective students, with a path to a native WordPress + Elementor build.

## Technologies

- **HTML5, CSS3 and vanilla JavaScript** — no frameworks or runtime dependencies
- **Node.js** static site generator that builds the whole site from one data source
- **Montserrat and Source Sans 3**, self-hosted
- **WebP images** with responsive `srcset`
- **JSON-LD** structured data, XML sitemap and `robots.txt`
- **Google Tag Manager–ready** analytics through `dataLayer`

## Features

### Finding a programme
- Course finder with filters for subject, level, study mode, intake and accreditation
- Side-by-side programme comparison (up to three)
- "Which programme is right for me?" guided quiz
- Site-wide search
- Audience entry paths and a finder form in the hero

### Applying and converting
- Multi-step enquiry form that pre-fills from the visitor's shortlist
- Fees and savings estimator (MUR and GBP, instalments, early-payment saving)
- Next-intake countdown that updates automatically
- Page-specific calls to action and "where next" guidance
- Sticky Apply, Call and Enquire actions on mobile

### Content and credibility
- Complete programme pages: overview, modules, assessment, careers, entry requirements, fees, FAQs
- Accreditation explorer and law career-route diagrams
- International student hub with a journey timeline and cost-of-living calculator
- Alumni, student stories and an interactive campus tour
- Guides with key takeaways and contents, events, gallery and student support hub

### Experience
- Full-screen cycling hero that simplifies cleanly on mobile
- Pre-loader, headline reveals, count-up statistics and parallax
- Back-to-top button with a scroll-progress ring
- Respects reduced-motion preferences

### Quality
- Accessible: semantic structure, keyboard navigation, visible focus, labelled forms
- Fast: lazy-loaded images, preloaded fonts, minimal JavaScript
- SEO-ready: clean headings, concise titles and descriptions, schema markup
